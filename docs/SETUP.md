# بيتنا — دليل التشغيل خطوة بخطوة

كل الأوامر تتشغّل من جوه فولدر `baytna-app`. الحسابات وكلمات السر والمفاتيح بتاعتك إنت، وما تتبعتش في الشات.

الترتيب: (1) و(2) يطلّعوا APK شغال على موبايل واحد. (3) يشغّل المزامنة بين الموبايلين. (4) يشغّل المساعد والبحث. (5) يخلّي التحديثات توصل من غير APK جديد.

## قبل ما تبدأ: لو أي أمر `npx` طلّع `ENOTDIR`

كاش npm على الجهاز ده متحوّل لقرص `E:`. لما القرص ده مش متوصّل، كل أوامر `npx` بتفشل برسالة `ENOTDIR ... npm-cache\_cacache`. المشروع فيه ملف `.npmrc` بيخلّي الكاش جوه فولدر التطبيق (`.npm-cache`)، فالأوامر بتشتغل طول ما إنت جوه فولدر `baytna-app`. بره الفولدر ده المشكلة لسه موجودة لحد ما القرص يتوصّل.

## 1. بناء الـ APK

محتاج حساب Expo مجاني من expo.dev.

```bash
npx eas-cli login
```

```bash
npx eas-cli init
```

```bash
npx eas-cli build -p android --profile preview
```

آخر أمر بياخد حوالي ربع ساعة وبيطلّع رابط تنزيل. افتحه من الموبايل ونزّل التطبيق.

## 2. أول تشغيل على الموبايل

- افتح الإعدادات جوه التطبيق واكتب الميزانية واسمك وأفراد البيت.
- جرّب: اعمل خطة الأسبوع، أضف مكونات وجبة، علّم صنف "اتشترى".
- بصّ على اتجاه الكتابة والأيقونات، وقولّي لو فيه حاجة مش مظبوطة. دي أول مرة التطبيق يشتغل على موبايل حقيقي.

## 3. المزامنة بين الموبايلين (Supabase)

1. اعمل مشروع جديد من supabase.com (الخطة المجانية كفاية).
2. من Authentication ثم Sign In / Providers فعّل **Anonymous sign-ins**.
3. من SQL Editor شغّل محتوى `supabase/schema.sql`.
4. من Project Settings ثم API انسخ **Project URL** و **anon public key**.
5. انسخ `.env.example` إلى `.env` وحط القيمتين. المفتاح ده عام ومحمي بصلاحيات الصفوف. مفتاح `service_role` عمره ما يتحط هنا.
6. ابني الـ APK من جديد (خطوة 1، آخر أمر) ونزّله على الموبايلين.
7. على موبايلك: الإعدادات ثم "اعمل بيت جديد". على موبايل شيماء: اكتب الكود اللي ظهر عندك واضغط "انضم".

## 4. المساعد والبحث عن أحسن سعر

محتاج خطوة 3 الأول، ومفتاح من console.anthropic.com (الدفع بالاستخدام).

1. من SQL Editor شغّل محتوى `supabase/price-search.sql`. ده بيحط حد 20 طلب في اليوم لكل مستخدم و100 للمشروع.
2. ثبّت أداة Supabase وادخل:

```bash
npx supabase login
```

```bash
npx supabase link
```

3. حط مفتاح Anthropic كسر على الخادم. اكتب المفتاح مكان النقط في الطرفية عندك، مش في الشات:

```bash
npx supabase secrets set ANTHROPIC_API_KEY=...
```

4. انشر الخادمين:

```bash
npx supabase functions deploy price-search
```

```bash
npx supabase functions deploy assistant
```

5. افتح تبويب "المساعد" وجرّب: "ضيف لبن للقائمة"، وبعدها "عايز فيديو لطريقة الكبسة".

لو المساعد ما ردّش: من لوحة Supabase افتح Edge Functions ثم Logs وابعتلي رسالة الخطأ من غير أي مفاتيح.

## 5. تحديثات من غير APK جديد (EAS Update)

بعد الخطوة دي أي تعديل في الشاشات أو المنطق يوصل للموبايلين لما التطبيق يتفتح. إضافة مكتبة فيها كود أندرويد (زي الصوت) لسه محتاجة APK جديد.

```bash
npx expo install expo-updates
```

```bash
npx eas-cli update:configure
```

```bash
npx eas-cli build -p android --profile preview
```

وبعد كده، كل ما يبقى فيه تعديل:

```bash
npx eas-cli update --branch preview --message "وصف التعديل"
```

الخطوة دي لسه ما اتظبطتش في المشروع، فأول مرة تنفّذها قولّي عشان أراجع الإعدادات معاك.

## 6. الدخول بحساب جوجل وبيت بدورين

الكود مكتوب وما اتجرّبش على موبايل. مشروع Supabase شغّال (16 نوفمبر 2026)، والمكتبة موجودة في الـ APK، فالتفعيل بيوصل بتحديث من غير APK جديد.

1. افتح console.cloud.google.com واعمل مشروع جديد.
2. من Google Auth Platform ظبّط شاشة الموافقة: اسم التطبيق "بيتنا" وإيميلك. الصلاحيات المطلوبة الإيميل والملف الشخصي بس.
3. اعمل عميل OAuth من نوع **Web application**. هيطلّع Client ID وسر.
4. بصمة التوقيع SHA-1 بتاعة التطبيق (مقروءة من الـ APK نفسه، وهي عامة مش سر):

```
90:C1:74:C2:C1:C8:FE:1E:D0:22:CE:1A:79:7E:2B:BF:2E:0C:75:F7
```

5. اعمل عميل OAuth تاني من نوع **Android** باسم الحزمة `com.baytna.app` والبصمة دي.
6. في لوحة Supabase: Authentication ثم Sign In / Providers ثم Google. فعّله، وحط Client ID والسر بتوع عميل الويب، وضيف Client ID بتاع عميل الأندرويد في خانة Client IDs.
7. في `.env` ضيف السطر ده بـ Client ID بتاع عميل **الويب** (ده عام، مش سر):

```
EXPO_PUBLIC_GOOGLE_WEB_CLIENT_ID=...
```

8. انشر تحديث (القسم 5). بعده زرار "ادخل بحساب جوجل" بيظهر في الإعدادات قبل إنشاء البيت.

`supabase/family.sql` اتطبّق على المشروع يوم 16 نوفمبر 2026: إنشاء البيت والانضمام له بقوا بحساب جوجل بس، والعضو الجديد بيستنى موافقة صاحب البيت من الإعدادات. الصلاحيات اتجرّبت على القاعدة نفسها (11 حالة). الواجهة ما اتجرّبتش على موبايلين حقيقيين لسه. الملف مفيهوش أي أمر حذف: العضو اللي بيترفض أو يخرج بيتعلّم عليه بتاريخ في `removed_at`.

طول ما تطبيق جوجل في وضع الاختبار، أي حساب هيدخل لازم يتضاف كمختبر من صفحة Audience في Google Cloud.

## 7. خرائط جوجل: "دوّر حواليا"

الكود مكتوب وما اتجرّبش. محتاج حساب فوترة على Google Cloud (فيه حصة مجانية شهرية).

1. في نفس مشروع Google Cloud فعّل حساب الفوترة.
2. حط **حد إنفاق** أو تنبيه ميزانية من Billing ثم Budgets & alerts، عشان الاستخدام ما يعدّيش المجاني من غير ما تعرف.
3. من APIs & Services ثم Library فعّل: **Places API (New)** و **Routes API**.
4. من Credentials اعمل API key، وقيّده على الخدمتين دول بس.
5. حطه كسر على الخادم (في الطرفية عندك، مش في الشات):

```bash
npx supabase secrets set GOOGLE_MAPS_API_KEY=...
```

```bash
npx supabase functions deploy places
```

6. افتح العروض واضغط "دوّر حواليا". التطبيق هيطلب إذن الموقع وقت الضغط بس.

لو ما رجعش نتايج: ابعتلي رسالة الخطأ من Edge Functions ثم Logs من غير المفتاح. أسماء حقول مواعيد العمل وشكل رد المسافات ممكن يحتاجوا تظبيط على أول تشغيل.

## 8. الإشعارات

لسه ما اتبنتش. لما تتبني هتحتاج:

- مشروع Firebase وتطبيق أندرويد باسم الحزمة `com.baytna.app`، وملف `google-services.json` يتحط في جذر `baytna-app`.
- مفتاح حساب خدمة من Firebase يترفع بـ `npx eas-cli credentials`.
- تفعيل "حماية الإرسال" من expo.dev ورمز الوصول يتحط كسر على Supabase.

## 9. يوتيوب والقنوات

دالة يوتيوب على الخادم لسه ما اتبنتش. اللي شغال دلوقتي من غير أي مفتاح: تلصق رابط فيديو على أي وجبة، والتطبيق يعرض صورته ويفتحه في تطبيق يوتيوب.

لما الدالة تتبني هتحتاج: تفعيل **YouTube Data API v3** في نفس مشروع Google Cloud، ومفتاح API يتحط كسر على Supabase. حصة البحث 100 طلب في اليوم حسب وثائق جوجل وقت كتابة الدليل.

## ملخص المفاتيح

| المفتاح | فين يتحط | سر؟ |
|---|---|---|
| `EXPO_PUBLIC_SUPABASE_URL` و `EXPO_PUBLIC_SUPABASE_ANON_KEY` | `.env` | لأ، عام |
| `EXPO_PUBLIC_GOOGLE_WEB_CLIENT_ID` | `.env` | لأ، عام |
| سر عميل الويب بتاع جوجل | لوحة Supabase | أيوه |
| `ANTHROPIC_API_KEY` | سر على Supabase | أيوه |
| `GOOGLE_MAPS_API_KEY` | سر على Supabase | أيوه |

## ملاحظات

- اللي لسه ما اتبناش: تحديث العروض تلقائي كل يوم، ومزامنة العروض وتفضيلات المساعد بين الموبايلين.
